# Architect review of model-gateway-go-port.v2.md (second round)

Condensed by the lead at 2026-11-25 22:27:28 JST from the reviewer's team message; the full text is in the session transcript.
Verdict: SOUND WITH CHANGES. Phase 0 may start after user approval as foundations and feasibility work (T0.0, T0.1; make CI or
a disposable VM the process-test default before T0.4; amend T0.3's JSON oracle first). Later gates must not be frozen as written.

## Ranked findings
1. CRITICAL — the lifecycle lock is not a migration fence for all legacy writers. Node compares hostname, pid and exact
   startedAt text; TZ differences can make a live lock look stale; a waiter acquires after release; a disabled `ensure` returns
   before the lock (commands.js:577-585,627-631,3043-3044); `env`, `pin`, direct `serve-shim` and the registry writer do not
   take the lock (hooks/registry-writer.js:145-155,192-201). Fix: an offline, operator-exclusive maintenance contract; verify
   what can be verified, require attestation for the rest; the new publisher inert until commit and disabled before rollback.
2. CRITICAL — migration has impossible states: a stopped gateway has no listener for step 2 and no /healthz for step 5; "not
   running, no marker" is not distinguished from "running"; 3 s after SIGTERM does not mean "not stopped"; Node stops only the
   proxy it spawned (process-supervision.js:1056-59,1076-89,1163-66,1201-08). Fix: observe marker and process state
   independently; specify outcomes for running, intentionally stopped, vacant unmarked, orphaned, external proxy.
3. CRITICAL — rollback is not a transaction: old field values and two launcher copies cannot reproduce byte-identical settings;
   breadcrumb pre-image, absence versus value, proxy binary state are missing; compare/read/rename is not an atomic conditional
   update. Fix: journal pre/post images and ownership before each side effect; quiesce the new writer first; whole-file restore
   only on exact post-image, otherwise field merge or a reported conflict; a maintenance exclusion requirement.
4. MAJOR — T2.0b confounds launch feasibility with functional completeness: four of the five proof cases need features built
   later (relay-stream-abort:66-87; thread-negotiation:111-174; tool-search:110-140; shim-upload-abort:181-219). Only the
   SIGTERM case (gateway-drain:390-424) and the PID equality alone are skeleton-sized. Fix: launch-only probes early; a separate
   pass with complete unchanged tests when their features exist; classification and expected results before the work they judge.
5. MAJOR — adapter 1 (process.execPath override) is conditionally feasible, not transparent: fixtures copy or link
   process.execPath (discovery-cache:71-79; gateway-process-isolation:198-207), some replace NODE_OPTIONS
   (codex-upstream-cases:239-252), preloads patch child_process in-process. Prefer adapter 2: keep process.execPath real and
   redirect only identified gateway launches at the harness seams (support.js:766-783) and audited direct spawn sites. Attribute
   per named test, not per file; behavioral require(CLI) assertions become go-port, not js-only.
6. MAJOR — D10 is safe to refuse but not recoverable: atomic replace does not cover spawn-to-record, the pid/json pair,
   deletion or a failed write; with a missing record `stop` cannot stop a healthy owned gateway. Device/inode is required by the
   sweep rule but absent from the record. Fix: the supervisor publishes and reconciles its own record before readiness;
   validate root, role, generation, port and live identity; on loss refuse with recovery instructions or use an authenticated
   instance-bound local channel; pin an immutable staged executable for durable launches.
7. MAJOR — relay and provider cancellation do not compose automatically: Request.Context is cancelled on disconnect;
   WithoutCancel strips deadlines; a ResponseWriter is invalid after return; the worker sees the supervisor socket, not the
   client. Specify behavior before full upload, before worker connect, before headers, during stream and after disconnect, for
   direct and relayed clients; abort a truncated committed response (http.ErrAbortHandler). GetBody=nil does not stop retries of
   bodyless idempotent requests on pooled connections; state HTTP versions.
8. MAJOR — jsontext is a tokenizer/encoder, not the wire algorithm: CanonicalizeRawFloats saturates 1e400 (JS emits null);
   AllowInvalidUTF8 maps to U+FFFD and cannot keep lone surrogates distinct. Needs Node-compatible byte-to-string decoding,
   UTF-16-aware keys and scalars, last-value/first-slot collapse, array-index ordering, nonfinite to null. File goldens must be
   authored, not generated by Node pretty-stringify; decide duplicate owned keys; drop the "Claude Code can produce" qualifier.
9. MAJOR — shadow preflight rejects any dial to a default port, which forbids using the live proxy; `shadow report` is not in the
   allowlist and has no owner; the soak log lacks session/agent correlation, effective trigger and compaction outcome; the
   readiness check spawns an auth-status subprocess. Choose a dedicated proxy or an explicitly allowlisted dial-only.
10. MAJOR — sandbox tiers are not yet enforceable: one negative decoy cannot distinguish "denies everything" from useful
    confinement; an env guard cannot bind a stripped-env child; a missing guardian.pid is not evidence of a safe host. Make
    macOS CI or a disposable VM the default; build tags for Tier 2; prove positives and negatives for the local profile.
11. MAJOR — descriptor mode omits cases: a preconfigured nonzero worker port is supervised without a report; RC binding depends
    on the presence of CODEX_GATEWAY_WORKER_PORT (request-worker.js:2710-2714), not on a mode; fixed fd numbers, malformed fd
    failure, report deadline versus respawn backoff, same-version orphan remediation.

## Resolution of the first review
All ten first-round defects: PARTLY RESOLVED (remaining conditions are the findings above). Differences: strict CLI, exec-form
hooks, kept birth records, withdrawn fast-path change and withdrawn config fallback are RESOLVED; atomic files, RC token, proxy
adoption, disconnect, backoff, gate budget and lexical settings are PARTLY RESOLVED. Note: pflag's unknown-flag allowlist
consumes a following non-flag argument (pflag flag.go:961-1006) while the source scans argv (commands.js:199-201).
